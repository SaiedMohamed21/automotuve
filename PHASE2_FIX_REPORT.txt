================================================================================
PHASE 2 — FIX REPORT: Accountant Parts Access & Part Management Permissions
================================================================================

We have completed Phase 2 successfully.
The Accountant Parts authorization bug (403 Forbidden on GET /api/warehouse/parts) has been resolved, and full Part Management permissions (Create Part, Edit Part, View Selling Price, Update Selling Price) are restored and persisted to SQL Server DB for Accountant users. Warehouse role restrictions on Selling Price remain strictly enforced at both backend and frontend levels.

--------------------------------------------------------------------------------
A. ROOT CAUSE OF ACCOUNTANT PARTS 403
--------------------------------------------------------------------------------
WarehouseController at Controllers/Warehouse/WarehouseController.cs (line 8) was decorated with [Authorize(Roles = "Warehouse,Owner,Engineer")]. Because the Accountant role was omitted from this attribute, any attempt by an Accountant user to fetch GET /api/warehouse/parts returned an HTTP 403 Forbidden status code. In addition, WarehouseController.CreatePart previously forced SellingPrice and PurchasePrice to 0 for any non-Owner role, which unintentionally wiped prices for Accountants as well.

--------------------------------------------------------------------------------
B. EXACT ENDPOINTS CHANGED
--------------------------------------------------------------------------------
1. GET /api/warehouse/parts — Now accessible by Accountant in addition to Warehouse, Owner, and Engineer.
2. GET /api/warehouse/parts/{id} — Now accessible by Accountant.
3. POST /api/warehouse/parts — Now accessible by Accountant. Preserves SellingPrice and PurchasePrice when created by Accountant or Owner.
4. GET /api/warehouse/movements — Now accessible by Accountant.
5. PUT /api/accountant/parts/{partId}/prices — Used by Accountant and Owner to update part prices and persist changes directly to SQL Server DB.

--------------------------------------------------------------------------------
C. EXACT AUTHORIZATION CHANGES
--------------------------------------------------------------------------------
In Controllers/Warehouse/WarehouseController.cs:

Before:
[Authorize(Roles = "Warehouse,Owner,Engineer")]

After:
[Authorize(Roles = "Warehouse,Owner,Engineer,Accountant")]

In CreatePart method (WarehouseController.cs):

Before:
if (!User.IsInRole("Owner"))
{
    dto.SellingPrice = 0;
    dto.PurchasePrice = 0;
}

After:
if (User.IsInRole("Warehouse") && !User.IsInRole("Owner") && !User.IsInRole("Accountant"))
{
    dto.SellingPrice = 0;
    dto.PurchasePrice = 0;
}
